## Avant le jeu

- Vérifier l’identité visuelle actuelle, la légitimité du nom, les autorisations et la présence du nom dans le logo.
- Sur un logo qui affiche « SCC », proposer « SCC » comme choix rend la question triviale, même avec une entreprise rare.
- Éviter les distracteurs absurdes et mélanger banques avec banques, cimentiers avec cimentiers, etc.
- Ne pas importer ce catalogue directement ; produire uniquement les lots validés via `valider_et_exporter.py`.
